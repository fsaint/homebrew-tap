# fsaint/homebrew-tap

Homebrew formulas for [fsaint](https://github.com/fsaint)'s tools.

```bash
brew install fsaint/tap/arev
```

| Formula | What it is |
|---|---|
| [`arev`](https://github.com/fsaint/arev) | Asset review loop for AI agents: submit images, videos and PDFs for human review and get structured feedback back. |
